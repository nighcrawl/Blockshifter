Every block on this page is a native WordPress block: two Gallery blocks and a Query Loop. Blockshifter only changes how they look on the front end. Click Edit Page in the toolbar above, select a block, and open the Blockshifter panels in the sidebar: one toggle turns it on or off.

A Gallery block, shifted into a Carousel

A Gallery block, shifted into a Masonry grid

A Query Loop, shifted into a Carousel of your latest posts

Deactivate Blockshifter and nothing breaks: these blocks simply go back to a regular Gallery and a regular post list.
