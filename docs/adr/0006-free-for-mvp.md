# Gratuit pur pour le MVP, aucune mécanique de licence codée

Aucun mécanisme de paiement/licence n'est implémenté dans le MVP — tous les Modules livrés sont gratuits. Le registre explicite de Modules (ADR-0004) reste desactivable individuellement pour raisons techniques (débogage, dépendances), mais ça ne préjuge d'aucune décision business : un modèle freemium par Module reste une option future non actée, à trancher séparément si besoin.
