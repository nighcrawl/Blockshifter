# L'interface Blocktopus_Transform ne couvre que le rendu PHP, pas les Inspector Controls JS

`Blocktopus_Transform` (PHP) impose uniquement ce qui concerne le rendu front : `ALLOWED_BLOCKS`, la clé de config dans `blocktopusConfig`, et une méthode `render()`. Les Inspector Controls (JS, édité dans `src/index.js`) suivent leur propre convention côté JS, sans interface PHP formelle les couvrant. Les deux moitiés d'un Module (PHP et JS) sont reliées uniquement par un `slug` commun et la forme partagée de `blocktopusConfig[slug]` — pas par un contrat unifié. Alternative rejetée : une interface unique pilotant PHP et JS, jugée sur-ingénierie pour un couplage aussi simple.
