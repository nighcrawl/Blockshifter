# Nom "Blocktopus" conservé malgré une collision hors-WordPress

Vérification effectuée : le slug `blocktopus` est disponible sur WordPress.org (aucun plugin existant). Le nom "Blocktopus" est en revanche déjà utilisé par plusieurs entités du secteur crypto/blockchain (plateforme KYC, société de conseil "Blocktopus Ltd", toolkit "Bloctopus"). Décision : conserver le nom, le secteur (plugin WordPress de blocs Gutenberg) étant suffisamment distinct pour ne pas créer de confusion réelle avec ces usages crypto/finance.
